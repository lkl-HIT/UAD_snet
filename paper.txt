# SimpleNet算法核心内容提炼

## 1. 算法目标
SimpleNet是一种用于图像异常检测与定位的简单高效网络，主要用于工业视觉检测场景。其核心思想是利用预训练特征，通过特征空间的噪声扰动和判别器实现异常区域的检测和定位。

## 2. 算法结构
SimpleNet包含四个主要模块：
1. **特征提取器（Feature Extractor）**：
   - 使用预训练CNN（如WideResNet50）提取输入图像的局部特征。
   - 支持多层级特征融合，提升对不同尺度异常的感知能力。
2. **特征适配器（Feature Adaptor）**：
   - 将预训练特征通过简单的全连接层（如单层MLP）投影到目标域，缓解工业数据与ImageNet分布不一致的问题。
   - 适配后的特征用于后续异常样本的生成和判别。
3. **异常特征生成器（Anomalous Feature Generator）**：
   - 在特征空间对正常样本添加高斯噪声，生成伪异常特征。
   - 噪声服从N(0, σ^2)，σ为超参数，控制异常特征与正常特征的距离。
   - 训练时，异常特征与正常特征共同用于判别器训练。
4. **判别器（Discriminator）**：
   - 采用两层MLP结构，对每个空间位置的特征进行判别，输出异常分数。
   - 判别器对正常特征输出正分数，对异常特征输出负分数。

## 3. 训练流程
- 输入正常样本，提取局部特征并适配。
- 对适配特征添加高斯噪声，生成异常特征。
- 判别器分别对正常和异常特征进行判别，输出分数。
- 损失函数采用截断L1损失，鼓励判别器对正常特征输出高分，对异常特征输出低分。
- 训练伪代码如下：
  1. 提取正常特征q，生成异常特征q'（加噪声）
  2. 判别器分别判别q和q'，输出分数
  3. 计算损失：loss = max(0, th+ - D(q)) + max(0, D(q') - th-)
  4. 反向传播，更新参数

## 4. 推理流程
- 推理时不再生成异常特征，仅对输入图像提取特征并适配。
- 判别器对每个空间位置输出异常分数，负分数表示异常。
- 通过高斯滤波平滑异常分数，得到最终的异常热力图。
- 最大异常分数作为整图异常检测分数。

## 5. 关键创新与优势
- 在特征空间而非像素空间生成异常，提升了泛化性和效率。
- 结构极简，推理速度快，适合工业部署。
- 单流结构，所有模块均为标准CNN和MLP，易于实现和维护。
- 适配器缓解了预训练特征与工业数据分布不一致的问题。

## 6. 伪代码（PyTorch风格）
```
# F: 特征提取器  G: 特征适配器  N: 高斯噪声  D: 判别器
for x in data_loader:
    q = G(F(x))           # 正常特征
    q' = q + random(N)    # 异常特征
    loss = loss_func(D(q), D(q'))
    loss.backward()
    update(D, G, F)
```

## 7. 主要超参数
- 高斯噪声标准差σ（如0.015）
- 判别器阈值th+、th-（如0.5, -0.5）
- 特征适配器结构（如单层MLP）
- 特征提取层级（如ResNet50的2,3,4层）
